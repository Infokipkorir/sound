Login History

Admin sign-in activity

No login history is being recorded yet — the current login flow (in auth.js) checks the admin_users table but never writes a record anywhere when someone signs in. This page can't show real data until that logging exists.

To make this page real, two small changes are needed:

  1. Add an admin_login_history table: id, admin_id, username, ip_address, user_agent, success, created_at.
  2. In auth.js's login flow, insert a row into it on every attempt (success and failure) — IP address would need to come from a small server-side function or edge function, since the browser can't reliably read its own public IP.
